# web

Дашборд Botsight (раздел 16 [Botsight.md](../Botsight.md)): React, TypeScript, Vite, TanStack Query, React Router, ECharts.

## Запуск

Нужен поднятый бэкенд (`docker compose -f deploy/docker-compose.yml up --build` из корня):

```bash
cd web
npm install
npm run dev          # http://localhost:5173, /v1 проксируется на api (localhost:8080)
```

Данные для графиков даёт `loadgen` (см. [backend/README.md](../backend/README.md)): он печатает почту аккаунта, пароль — `loadgen-password`.

## Как устроено

- **Типы API генерируются из OpenAPI:** `npm run gen:api` создаёт `src/api/schema.d.ts` из `backend/api/openapi.yaml`, клиент `openapi-fetch` типизирует пути, параметры и ответы. CI перегенерирует файл и падает, если он расходится со спецификацией: дашборд и API не разъезжаются.
- **Сессия.** Сессия живёт в cookie `bs_session` (HttpOnly). CSRF-токен из ответа входа или `GET /v1/account` хранится только в памяти и уходит в `X-CSRF-Token` на изменяющих запросах. `401` на любом запросе сбрасывает аккаунт и ведёт на вход с возвратом на ту же страницу; перенаправление принимает только пути этого сайта.
- **Один origin.** В разработке Vite проксирует `/v1` на `api`, поэтому cookie `SameSite=Lax` работает без CORS.
- **Период в URL** (`?range=30d&tz=Europe/Moscow`): ссылка показывает коллеге тот же срез, а все графики страницы читают один период.
- **Ключ проекта** показывается один раз и передаётся на экран подключения в памяти, не в URL.
- **Живая лента и экран «Ждём первое событие…»** работают на `EventSource` к `/live` (SSE): переподключение встроено, повтор события после переподключения отсеивается по `event_id`.
- **Графики** построены по правилам визуализации:
  - валидированная палитра с фиксированным порядком цветов, светлая и тёмная темы на своих выбранных оттенках, а не на инверсии;
  - линии 2 px, столбцы не шире 24 px со скруглённым концом, сплошная сетка в волос;
  - легенда начиная с двух серий, подпись только на конце линии;
  - одна подсказка на все серии, значение первым;
  - отметки запусков бота на оси дней;
  - у каждого графика есть табличный вид;
  - при перезагрузке данных предыдущий кадр остаётся приглушённым, без скелетонов.
- **Код графиков грузится лениво:** ECharts уходит в отдельный чанк, вход и список проектов открываются без него.

## Проверки

```bash
npm run typecheck
npm test             # vitest: форматирование, период, живая лента, клиент API, отметки деплоев, раскладка графа, тепловая шкала
npm run e2e          # Playwright против запущенного стека и `npm run build && npx vite preview`
```

e2e в CI запускается после `loadgen` в общем окружении docker compose. Проверяются два сценария:
- регистрация → проект → ключ → батч в collector → «Бот подключён» на живой ленте;
- обзор с данными, табличный вид и смена периода;
- воронка считается, остальные экраны аналитики открываются без ошибок;
- новый ключ и расход в настройках, фермы на антифроде, рассылка от предпросмотра до списка.
